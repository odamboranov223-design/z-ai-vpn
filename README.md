# Z AI VPN

Windows-клиент, который подключается к серверам **по ссылке**. Никаких внешних
`xray.exe`, `geoip.dat` и прочих файлов рядом с программой: движок Xray-core
встроен в исполняемый файл, интерфейс тоже встроен.

Полностью **монохромный** интерфейс — только чёрный, белый и оттенки серого.
Никакого цвета. Премиальная типографика, анимированный power-диал, живой
connection orb с вращающимися кольцами, пинг-бары вместо цифр, страны в виде
двухбуквенных кодов (DE, NL, US…), нижний status-strip с IP и сессией.

## Что умеет

- **Подписка по ссылке**: base64-список, обычный список, JSON-конфиги Xray
- **Импорт из буфера**: `vless://`, `vmess://`, `trojan://`, `ss://`
- **Транспорты**: TCP, WebSocket, gRPC, XHTTP, HTTPUpgrade, mKCP
- **Защита**: TLS, REALITY, uTLS-отпечатки
- **Пинг серверов**, проверка публичного IP после подключения
- **Системный прокси** Windows (HTTP `127.0.0.1:10809`, SOCKS `127.0.0.1:10808`)
- **Российские сайты напрямую** (переключатель)
- Данные в `%APPDATA%\ZAIVPN`

## Сборка

```bash
go build -trimpath -ldflags "-s -w" -o ZAIVPN.exe ./cmd/z-ai-vpn
```

Нужен Go 1.27 или новее. Кросс-компиляция под Windows из Linux:

```bash
GOOS=windows GOARCH=amd64 go build -trimpath -ldflags "-s -w" -o ZAIVPN.exe ./cmd/z-ai-vpn
```

Готовые сборки лежат в **Releases**.

## Использование

```
ZAIVPN.exe                      # открыть окно
ZAIVPN.exe -add "vless://..."   # добавить сервер и выйти
ZAIVPN.exe -sub "https://..."   # добавить подписку и выйти
ZAIVPN.exe -no-window           # без окна, только локальный адрес
```

Если на машине нет WebView2 Runtime, окно не откроется — приложение покажет
локальный адрес, который нужно открыть в браузере.

## Устройство

```
cmd/z-ai-vpn         точка входа, разбор аргументов, локальный HTTP-сервер
internal/links         разбор ссылок (vless/vmess/trojan/ss/hysteria2/tuic)
internal/xraycfg       сборка JSON-конфигурации Xray из разобранной ссылки
internal/engine        встроенный Xray-core: старт, стоп, журнал
internal/app           сервис: хранилище, движок, системный прокси, подписки
internal/ui            HTTP-API и встроенные ассеты интерфейса (HTML/CSS/JS)
internal/window        нативное окно WebView2 (Windows)
internal/store         сохранение состояния в %APPDATA%\ZAIVPN
internal/country       определение страны по названию сервера
internal/subscription  загрузка подписок, заголовки провайдера
internal/sysproxy      системный прокси Windows
internal/netinfo       пинг и определение внешнего IP
```

## Дизайн

- **Палитра**: pure monochrome — `#050505` / `#0a0a0a` / `#161616` / `#f5f5f5`
- **Шрифты**: Inter для UI, JetBrains Mono для технических данных
- **Power-диал**: круглый SVG-тумблер с дугой статуса (OFF / Connecting / ON)
- **Connection Orb**: 220px круг с 3 вращающимися кольцами и ядром, меняющим
  заливку при подключении
- **Ping-bars**: 5 вертикальных полосок вместо чисел — чем выше заполнение,
  тем лучше пинг
- **Country codes**: `DE`, `NL`, `US` моноширинным шрифтом вместо цветных флагов
- **Status-strip**: внизу окна — IP, таймер сессии, текущий сервер, версия
- **Микро-анимации**: cubic-bezier везде, skeleton-загрузка, toast справа снизу

## Проверка

```bash
go vet ./...
go test ./...
```

Тесты поднимают настоящий Xray-сервер на localhost и прогоняют через него
HTTP-запрос, проверяя весь путь: ссылка → конфигурация → туннель → трафик.

## Ограничения

- `hysteria2://` и `tuic://` парсятся, но встроенный движок Xray их не умеет —
  они пока не подключаются.
- Полные базы `geosite`/`geoip` не встроены: правило «российские сайты напрямую»
  работает по списку доменов и TLD `.ru`/`.su`/`.xn--p1ai`.
